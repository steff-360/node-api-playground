# Node API Playground

Mini APIs REST construidas con Node.js y Express para practicar arquitecturas backend.

## Proyectos incluidos

```
/notes-api      - API de notas con CRUD completo
/tasks-api      - API de tareas con filtros y paginacion
```

## Requisitos

```bash
npm install
npm run dev
```

## Stack
- Node.js 18+
- Express.js
- PostgreSQL
- dotenv
